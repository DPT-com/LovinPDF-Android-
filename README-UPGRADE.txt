Lovin-PDF Android upgrade patch
================================
Includes custom launcher icon resources and Google AdMob TEST banner setup.

Important:
- This uses Google's official TEST App ID and TEST banner unit ID only.
- Test ads do not earn money. Do not replace these with live IDs until your AdMob app/ad unit is configured and policy requirements are met.
- PDF tools still open https://lovin-pdf.vercel.app/; this patch does not make PDF processing offline/native.
- Copy the files/folders from this ZIP into the root of your existing LovinPDF-Android project, merging folders and replacing the three matching files.
- Build through GitHub Actions after committing and pushing.
